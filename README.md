# NCA-GENL 模擬考

NVIDIA Certified Associate: Generative AI & LLMs（NCA-GENL）證照的**繁體中文模擬考**工具。

- 153 題題庫，含中英對照、逐選項解析
- 真實模擬模式：隨機抽 50 題 / 60 分鐘 / 70% 通過（對齊官方規格）
- 官方五大領域配分：Core ML & AI 30%、Software Development 24%、Experimentation 22%、Data Analysis 14%、Trustworthy AI 10%
- 交卷後依領域與細分主題分析得分；作答歷史存在你自己的瀏覽器（localStorage），不上傳

## 線上練習

開啟 GitHub Pages 網址即可，任何裝置、任何瀏覽器皆可使用，無需安裝。

## 本機使用

下載 `index.html`，用瀏覽器直接打開即可（純前端、離線可用、無後端）。
